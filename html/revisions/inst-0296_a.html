Create tasks

Turn discussion into action

Convert any note into an assigned task without leaving the conversation. The owner, due date, and original decision stay linked together.

Shortcut ⌘ + Shift + T

In this step

1

Select the note

Highlight a decision or next step inside the thread.

2

Choose Make task

Open the note tools and pick Make task from the menu.

3

Assign and save

Add an owner, set a due date, then confirm the task.
