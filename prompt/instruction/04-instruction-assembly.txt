Instruction generation: assemble individual requests
====================================================

SYSTEM
------
Join the requests into what one person would say in one go.
Add nothing, drop nothing, keep the order — it is already the order they should be
said in. Adjust only how the sentences connect.

You may put one short connective between two sentences where it helps. A connective
is all you may add — it names no element, no place, and no reason.
Every request must still be findable in the result, word for word.
Do not let them come out as a matched set. Real people do not give three requests the
same shape and the same weight in one breath — if two arrive with the same skeleton,
connect them differently rather than evenly.

Write the combined instruction in English.
Output: JSON and nothing else.
{"en": "..."}

USER TEMPLATE
-------------
These requests are already in the order they should be said.

[REQUESTS]
{requests}
